🔍 Navigation Debug Tool

Use this page to diagnose dropdown menu issues.

Quick Tests

Browser Console Commands

Open DevTools (F12) and paste these commands:

Check if dropdowns are hidden:

document.querySelectorAll('.nav-dropdown-items').forEach(el => {
  console.log('Display:', window.getComputedStyle(el).display);
  console.log('Visibility:', window.getComputedStyle(el).visibility);
  console.log('Position:', window.getComputedStyle(el).position);
});

Force show a dropdown:

document.querySelector('.nav-dropdown-items').style.cssText = 
  'display: block !important; visibility: visible !important; opacity: 1 !important;';

Check parent containers:

document.querySelectorAll('.navbar, .container-xl, header').forEach(el => {
  console.log(el.className, 'overflow:', window.getComputedStyle(el).overflow);
});

Find conflicting styles:

const dropdown = document.querySelector('.nav-dropdown-items');
const styles = window.getComputedStyle(dropdown);
console.log({
  display: styles.display,
  visibility: styles.visibility,
  position: styles.position,
  top: styles.top,
  left: styles.left,
  zIndex: styles.zIndex
});

Common Issues & Fixes

Issue: Dropdowns still visible

Cause: CSS not loaded or overridden

Fix:

  1. Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
  2. Clear browser cache completely
  3. Check Network tab in DevTools - verify CSS file loads
  4. Check for CSS errors in Console tab

Issue: Dropdowns don't appear on hover

Cause: z-index or positioning issue

Fix:

  1. Inspect parent element - should have position: relative
  2. Check dropdown z-index: 9999
  3. Verify pointer-events: auto on hover

Issue: Dropdowns cut off by parent container

Cause: Parent has overflow: hidden

Fix:

  1. Add to CSS: .navbar, .container-xl { overflow: visible !important; }
  2. Check all parent containers up to <body>

Expected CSS Values

display none block
visibility hidden visible
