## Agency Owner Guide

### Initial Setup

#### 1. Account Registration
1. Visit the registration page
2. Fill in your agency details:
   - Agency name
   - Owner name
   - Email address
   - Phone number
   - Business address
3. Create a secure password
4. Verify your email address
5. Complete agency profile setup

#### 2. Agency Profile Configuration
1. Go to **Settings** → **Agency Profile**
2. Upload your agency logo
3. Add business registration details:
   - GST number
   - PAN number
   - Business registration certificate
4. Set up billing address and contact information
5. Configure operational parameters:
   - Working hours
   - Overtime policies
   - Holiday calendar

#### 3. Initial User Setup
1. Navigate to **Admin** → **Users**
2. Create HR staff accounts:
   - Add name and email
   - Assign "HR" role
   - Send invitation email
3. Set up client access (if required):
   - Create client user accounts
   - Assign "Client" role
   - Link to specific client records

### Managing Your Agency

#### Client Onboarding
1. Go to **Admin** → **Clients** → **Add New**
2. Fill in client information:
   - Company name
   - Contact person details
   - Business address
   - Contact information
   - Service requirements
3. Set up service agreements:
   - Service type (static guards, mobile patrol, etc.)
   - Number of personnel required
   - Shift timings
   - Special requirements
4. Configure billing settings:
   - Service rates
   - Billing frequency
   - Payment terms
   - GST applicability

#### Staff Management

2. **Role Assignment**:

#### Financial Overview

#### Payroll Processing

##### Monthly Payroll Generation
1. **Preparation**:
   - Verify attendance data for the month
   - Check for any pending corrections
   - Review overtime and leave records
   - Confirm salary changes or increments

2. **Payroll Execution**:
   - Navigate to **Payroll** → **Generate Payroll**
   - Select the payroll period
   - Choose tax regime (Old/New)
   - Review employee list
   - Execute payroll processing

3. **Tax Calculations**:
   - **Old Tax Regime**:
     - Standard deduction: ₹50,000
     - Tax slabs as per old regime
     - Professional tax by state
   
   - **New Tax Regime**:
     - Standard deduction: ₹75,000
     - Revised tax slabs
     - No exemptions for 80C, HRA etc.

4. **Statutory Deductions**:
   - **EPF Calculation**:
     - Employee contribution: 12% of basic salary
     - Employer contribution: 12% of basic salary
     - Maximum basic for PF: ₹15,000
   
   - **ESIC Calculation**:
     - Employee contribution: 0.75% of gross salary
     - Employer contribution: 3.25% of gross salary
     - Applicable for salary up to ₹21,000
   
   - **Professional Tax** (varies by state):
     - Maharashtra: ₹175/month
     - Karnataka: ₹150/month
     - West Bengal: ₹110/month

##### Payslip Distribution
1. **Digital Distribution**:

2. **Physical Distribution**:

## Troubleshooting

### Common Issues and Solutions

#### Login Problems
**Issue**: Cannot log in to the system
**Solutions**:
1. Verify username and password are correct
2. Check internet connection
3. Clear browser cache or app data
4. Contact HR for password reset
5. Ensure account is not suspended

**Issue**: "Account locked" message
**Solutions**:
1. Contact HR immediately for account unlock
2. Wait for automatic unlock (usually 30 minutes)
3. Verify identity before account restoration

#### Attendance Issues
**Issue**: Cannot check in/out
**Solutions**:
1. Check GPS location is enabled
2. Ensure you're at the correct location
3. Try manual check-in option
4. Contact supervisor for assistance
5. Report technical issues to IT support

**Issue**: Location not recognized
**Solutions**:
1. Move to open area for better GPS signal
2. Wait for GPS to acquire accurate location
3. Use QR code option if available
4. Contact site supervisor for assistance

#### Payroll Questions
**Issue**: Payslip discrepancies
**Solutions**:
1. Review attendance records for the month
2. Check for any approved leaves or deductions
3. Contact HR with specific discrepancy details
4. Provide supporting documentation
5. Request detailed pay calculation

**Issue**: Missing payslip
**Solutions**:
1. Check email spam/junk folder
2. Log into employee portal
3. Contact HR for reissuance
4. Verify email address is current
5. Request alternative delivery method

#### Technical Support
**Issue**: Mobile app crashes or errors
**Solutions**:
1. Force close and restart app
2. Check for app updates
3. Clear app cache and data
4. Restart mobile device
5. Reinstall app if necessary
6. Contact IT support with error details

**Issue**: Web portal not loading
**Solutions**:
1. Try different web browser
2. Clear browser cache and cookies
3. Disable browser extensions
4. Check internet connection
5. Try accessing from different device
6. Contact IT support
